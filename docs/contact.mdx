## Developer and technical support

- **Technical support form:** [flare.network/resources/technical-support](https://flare.network/resources/technical-support) — dedicated Flare expert support for projects.
- **Telegram:** [t.me/FlareNetwork](https://t.me/FlareNetwork) — community Q&A and developer discussion.
- **GitHub:** [github.com/flare-foundation](https://github.com/flare-foundation) — issues and contributions for open-source repositories, including [developer-hub](https://github.com/flare-foundation/developer-hub).

## API keys and rate limits

Public Data Availability Layer and verifier endpoints work without a key, subject to public rate limits.
For higher limits, open an [API Key Request](https://github.com/flare-foundation/developer-hub/issues/new/choose) issue on GitHub.
API key guidance is summarized on the [Developer Portal](/developers#authentication).
The Data Availability OpenAPI spec is at [`/openapi/data-availability-api.yaml`](pathname:///openapi/data-availability-api.yaml).
