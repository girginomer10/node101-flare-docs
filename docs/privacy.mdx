This page summarizes how Flare Developer Hub relates to privacy for visitors, developers, and AI agents that crawl or call this site.
Flare Ecosystems Limited publishes the binding legal terms for Flare’s websites and services at [flare.network/privacy-policy](https://flare.network/privacy-policy).
If anything here conflicts with that policy, the flare.policy controls.

## What this site is

Flare Developer Hub (`https://dev.flare.network`) is a documentation site.
It publishes technical content (guides, references, OpenAPI specs, Markdown mirrors, `llms.txt`, and MCP discovery metadata) so humans and agents can build on Flare.

## Data we may process

Depending on how you use the site and related Flare services:

- **Server and CDN logs** — IP address, user agent, requested URL, and timestamps may be processed by hosting and CDN providers (for example GitHub Pages and Cloudflare) to deliver and secure the site.
- **Analytics** — the site may use Google Analytics / Google Tag Manager (see site configuration) with IP anonymization enabled where configured.
- **Cookies** — a cookie consent loader may run for analytics or similar optional tags; see the cookie script on the site.
- **Support and GitHub** — if you email [info@flare.network](mailto:info@flare.network), use the [technical support form](https://flare.network/resources/technical-support), or open a GitHub issue (including API key requests), you provide the personal data in that submission so we can respond.

This documentation site does not require an account to read docs.
Machine-readable resources such as `/openapi/data-availability-api.yaml`, `/llms.txt`, Markdown page mirrors (append `.md`), and the MCP server are intended for public developer use, subject to applicable rate limits and terms.
